- 대화가 끊겨도 GitHub 문서만으로 프로젝트 맥락과 다음 작업을 복원할 수 있어야 한다.

## 저장소 관찰 사실
- 저장소: https://github.com/useformotor3/ai-discord-bot
- 기본 브랜치: main
- 기존 구조: main.py, state.json, history.json, research_archive/, .github/workflows/run.yml
- 기존 조사 아카이브가 다수 존재한다. state.json의 누적 카운트 275는 실제 아카이브 파일 수와 대조되지 않았으므로 동일한 수치로 취급하지 않는다.
- 현재 워크플로는 workflow_dispatch와 repository_dispatch 트리거를 사용하며 cron 예약 실행은 확인되지 않았다.
- 기존 봇은 Gemini API로 CRA 조사, Discord 전송, Markdown 아카이브 및 상태/이력 저장을 수행하는 구조로 확인되었다. 상세한 코드 검증은 후속 작업이다.
