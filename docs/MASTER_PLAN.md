# CRA 서보 드라이브 개발 — 마스터 계획서

이 문서는 살아 있는 실행 계획서다. 모든 상태는 저장소 증거로 갱신하며, 계획·문서·폴더 구조·스키마·자동화 코드의 개선을 허용한다. 변경 이유와 영향을 SESSION_LOG에 남긴다.

## 완료 정의
각 핵심 요구사항에 ID, 공식 조항, 원문 위치, 번역·해석, 적용성 근거, 개발 조치, 시험 방법/기준, 객관적 증거, 검증 상태, 확인일이 연결되어야 한다. 미확인 내용은 완료로 표시하지 않는다.
