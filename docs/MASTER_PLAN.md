# CRA 서보 드라이브 개발 — 마스터 계획서

이 문서는 프로젝트의 살아 있는 계획서다. 사용자의 지시와 검증 결과에 따라 수정하며, 변경 이유는 Git 커밋과 SESSION_LOG에 남긴다.

## 목표와 산출물
- CRA 입문자용 설명부터 서보 드라이브 개발 실무 적용까지 연결한 통합 보고서
- 요구사항-설계조치-구현-시험-증거 간 추적성 매트릭스
- 기존 조사 자료 검증대장 및 출처/원문 인덱스
- ST MCU 중심 보안 설계 가이드와 TI 비교자료
- 개발 단계별 체크리스트와 출시 전 점검표

## 우선순위 규칙
1. 법령 원문 및 적용 범위 검증
2. 제품 경계와 적용성 판단
3. 필수 보안 요구사항과 개발 증거
4. ST MCU 기능의 실제 지원 여부
5. TI 비교 및 보완 자료
6. 보고서 편집·시각화·출력 자동화

## 완료 정의
각 핵심 요구사항은 최소한 다음 항목을 갖춰야 한다.
- 요구사항 ID 및 설명
- 공식 출처 URL과 문서 식별정보
- 원문 조항/페이지/절
- 한국어 해석과 해석상 한계
- 서보 드라이브에 대한 적용성 및 근거
- 하드웨어/펌웨어/프로세스 조치
- 시험 방법과 합격 기준(근거가 있을 때)
- 저장해야 할 객관적 증거
- 검증 상태와 마지막 확인일
