# 서보 드라이브 CRA 사용자 보안정보·지침서 체크리스트 (작업용 템플릿)

- 상태: TEMPLATE / PRODUCT-SPECIFIC ITEMS UNVERIFIED
- 기준: Regulation (EU) 2024/2847, Article 13(16)–(19), Annex II(1)–(9)
- 이 문서는 법정 “Digital Product Passport”가 아니다. 내부 산출물 명칭은 “제품 사이버보안 사용자 정보 패키지”로 한다. 실제 제품 경계·SKU·기능·의도된 용도·EU 공급 형태가 확인되기 전에는 적용성과 완료 상태를 확정하지 않는다.

## 상태 정의
- NOT_STARTED: 근거/문서 미수집
- DRAFT: 초안만 존재
- EVIDENCE_PENDING: 제품 증거 검토 대기
- VERIFIED: 승인된 제품 증거와 문서 대조 완료
- NOT_APPLICABLE: 비적용 사유와 근거 기록 완료
- NOT_RUN: 검토/시험 미수행

모든 항목의 초기 상태는 NOT_STARTED이다. 예시 질문은 해당 기능/데이터가 실제 제품에 존재한다는 의미가 아니다.

## C. 현재 미확정 제품 입력값

- 제조사, SKU/모델, HW/FW 리비전
- 제품 core functionality, intended purpose, 제품 경계 및 EU 공급 형태
- 실제 통신/서비스 인터페이스와 원격접속 기능
- 계정·인증·권한 모델
- 업데이트 경로, 자동 업데이트 기본값, 복구 방식
- 실제 저장소, 사용자 데이터, 로그, 인증서/키의 존재 여부
- 지원기간 산정 근거 및 예상 사용기간
- 통합자가 받아야 할 정보
- Annex III 제품 카테고리 및 core-function 증거(Important Product/Class I/Class II 판정용)

## D. 각 항목의 필수 추적 메타데이터
항목 ID, 개정번호, CRA 조항/공식 URL, 담당자·승인자, 적용 SKU/HW/FW, 원천 증거 파일·버전·날짜, 사용자 문서 섹션/페이지/URL, 상태, 검토일, 미해결 이슈, 번역/지역별 버전, 변경 이력.

## E. 작성 원칙
1. 법적 의무, 위험기반 설계 권고, 제품 사실, 내부 해석을 구분한다.
2. “Digital Product Passport”를 CRA Annex II의 법정 명칭으로 표현하지 않는다.
3. Annex II(9)의 SBOM 위치 안내는 제조사가 SBOM을 사용자에게 제공하기로 결정한 경우에만 해당한다.
4. Annex II(8)(e)는 자동 보안 업데이트 기본 설정을 끄는 방법에 관한 지침이다. 제품의 실제 동작을 확인하지 않고 문구를 넣지 않는다.
5. 안전한 데이터 삭제는 실제 저장소·데이터를 확인해 설계한다. 법령이 특정 암호학적 삭제 기술을 명시했다고 주장하지 않는다.
6. 산업용/서보 드라이브라는 이유만으로 Important Product Class II를 추정하지 않는다.
7. 미확인 항목은 UNKNOWN/UNVERIFIED로 유지한다. 초안 작성만으로 VERIFIED/PASS 처리하지 않는다.
